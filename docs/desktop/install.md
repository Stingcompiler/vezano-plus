# تثبيت فيزانو بلص للحاسوب

الحزم في صفحة **Releases** على GitHub، في إصدار اسمه «فيزانو بلص للحاسوب». حتى يتوفر توقيع آبل وتوقيع ويندوز، تُبنى الحزم **بلا توقيع**. التطبيق يعمل كاملاً، لكن النظام يعرض تحذيراً عند أول تثبيت. هذه خطوات تجاوزه مرة واحدة.

## ماك (macOS 13 فما فوق)

1. نزّل ملف `.dmg` من الإصدار، وافتحه.
2. اسحب **Vezano Plus** إلى مجلد **Applications**. (اسم الملف لاتيني لأن أداة مثبّت ويندوز لا تقبل الحروف العربية؛ داخل التطبيق كل شيء بالعربية.)
3. افتح **Vezano Plus**. تظهر رسالة «Apple could not verify "Vezano Plus"…». اضغط **Done**، **لا** «Move to Trash».
4. افتح **System Settings ← Privacy & Security** (الإعدادات ← الخصوصية والأمان)، وانزل إلى قسم **Security**. بجانب سطر «Vezano Plus» اضغط **Open Anyway** وأدخل كلمة مرور الجهاز، ثم **Open Anyway** مرة أخرى عند فتحه.
   - الزر الأيمن ← «فتح» لم يعد يكفي في macOS الحديث.
   - أو من الطرفية بأمر واحد بدل الخطوتين 3 و4 (يزيل علامة «نُزّل من الإنترنت» عن التطبيق وحده):

     ```bash
     xattr -dr com.apple.quarantine "/Applications/Vezano Plus.app"
     ```

5. بعدها يفتح التطبيق بالنقر العادي كأي تطبيق.

## ويندوز (10 و11)

1. نزّل ملف `.msi` (أو `-setup.exe`) من الإصدار، وشغّله.
2. إن ظهرت شاشة **Windows protected your PC**: اضغط **More info** ثم **Run anyway**.
3. أكمل التثبيت. إن لم يكن WebView2 مثبّتاً على الجهاز، يثبّته المثبِّت تلقائياً (يحتاج إنترنت).

## أول تشغيل

- ادخل بحسابك المعتاد. الجلسة تُحفظ في مخزن مفاتيح النظام (Keychain في ماك، وCredential Manager في ويندوز)، فلا تدخل من جديد عند كل فتح.
- من **الأجهزة والمزامنة ← الطابعة** اختر طابعة الإيصالات وطابعة التقارير. بعدها تُطبع الإيصالات مباشرة بلا حوار.
- التطبيق لا يُغلق ما دامت عمليات لم تُرفع بعد. يسألك: «أبقِه في الخلفية» أو «إغلاق».

## للمالك: تفعيل التحديث التلقائي (مرة واحدة)

التحديث التلقائي يحتاج مفتاح توقيع خاصاً بالتحديثات، منفصلاً عن شهادتَي آبل وويندوز ومجانياً. أنت تحفظه، لا المستودع. من طرفية على جهازك، داخل مجلد المشروع:

```bash
pnpm --filter @sting/desktop tauri signer generate -w ~/.tauri/vezano-plus.key
```

```bash
gh secret set TAURI_SIGNING_PRIVATE_KEY < ~/.tauri/vezano-plus.key
```

```bash
gh secret set TAURI_SIGNING_PRIVATE_KEY_PASSWORD
```

```bash
gh variable set VEZANO_UPDATER_PUBKEY < ~/.tauri/vezano-plus.key.pub
```

- الأمر الثالث يطلب كلمة المرور التي اخترتها في الأول. إن تركتها فارغة فاضغط Enter.
- احفظ `~/.tauri/vezano-plus.key` في مكان آمن. إن ضاع، لن تستطيع النسخ المثبَّتة التحقق من أي تحديث جديد، وسيلزم تثبيت يدوي مرة واحدة.

بعدها يحمل كل إصدار ملف `latest.json` وتواقيع التحديث. التطبيق المبني بالمفتاح يعلن التحديث في **الأجهزة والمزامنة ← تحديث التطبيق** (DESK-01)، ولا يثبّته فوق عمليات لم تُرفع.

## إصدار جديد

```bash
git tag desktop-v0.1.0
```

```bash
git push origin desktop-v0.1.0
```

يبني CI حزم ماك وويندوز ويضعها في إصدار **مسوّدة**. راجعه في صفحة Releases ثم اضغط **Publish**. قبل النشر لا يراه التطبيق ولا المستخدمون.

## حين تتوفر الشهادات

- **آبل:** أضف الأسرار `APPLE_CERTIFICATE` و`APPLE_CERTIFICATE_PASSWORD` و`APPLE_SIGNING_IDENTITY` و`APPLE_ID` و`APPLE_PASSWORD` و`APPLE_TEAM_ID`. الإصدار التالي يُوقَّع ويوثَّق تلقائياً، فيختفي تحذير ماك.
- **ويندوز:** تُضاف خطوة التوقيع في `desktop-release.yml` حسب نوع الشهادة (Azure Trusted Signing أو شهادة OV).
