# تطبيق فيزانو بلص للحاسوب (ويندوز وماك)

كل ما يخص تطبيق الحاسوب، والشيفرة نفسها في [`apps/desktop`](../../apps/desktop).

| الملف | المحتوى |
|---|---|
| [plan.md](plan.md) | الخطة المعتمدة: المبدأ (طبق الأصل من الويب)، والطبقة الخاصة بكل منصة، والمراحل ط١–ط٧ |
| [install.md](install.md) | التثبيت على ماك وويندوز (حزم بلا توقيع)، ومفتاح التحديث التلقائي، وإصدار نسخة جديدة |

## القرارات

في سجل القرارات [`docs/decisions/0005-…`](../decisions/0005-acc-01-02-frame-conflicts-and-identity.md):

| القسم | الموضوع |
|---|---|
| §٢٠٦ | طبق الأصل من الويب: الشاشات تُستورد كما هي، والمسارات تُولَّد من صفحات الويب |
| §٢٠٧ | الجلسة في مخزن مفاتيح النظام، وCORS لأصلَي التطبيق في الخادم |
| §٢٠٨ | شاشات الحاسوب DESK-01…05 |
| §٢٠٩ | الطباعة الحرارية المباشرة، وتنفيذ الاختصارات داخل البيع، وقائمة ماك |
| §٢١٠ | الحزم في إصدار مسوّدة، والتحديث التلقائي الموقَّع |

## أين ماذا في الشيفرة

| المسار | الدور |
|---|---|
| `apps/desktop/src/generated/routes.ts` | جدول المسارات، مولَّد من `apps/web/src/app` (`scripts/gen-routes.mjs`) |
| `apps/desktop/src/shims/` | بديلا `next/navigation` و`next/link` فوق React Router |
| `apps/desktop/src/platform/` | طبقة المنصة: مخزن المفاتيح، والطباعة، وحفظ الملفات، والاختصارات، والتنقل، والقائمة |
| `apps/desktop/src/screens/` | شاشات الحاسوب وحده DESK-01…05 |
| `apps/desktop/src-tauri/` | الغلاف الأصلي (Rust): مخزن المفاتيح، وطابعات النظام والطباعة الخام، وحفظ الملفات، وقائمة ماك، والمحدِّث |
| `apps/desktop/e2e/` | مواصفات شاشات الحاسوب؛ ومواصفات الويب نفسها تعمل على بنائه (`playwright.config.ts`) |
| `backend/sting/desktop_cors.py` | السماح لأصلَي التطبيق بطلب `/api/` |
| `.github/workflows/desktop-release.yml` | بناء حزم ماك وويندوز في إصدار مسوّدة عند وسم `desktop-v*` |
